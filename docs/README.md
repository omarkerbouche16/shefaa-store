Build the project from these documents in order:

2. `02-brand-identity.md`
3. `03-ux-cro-strategy.md`
4. `04-site-map-and-page-specs.md`
5. `05-product-copy-and-offers.md`
6. `06-frontend-architecture.md`
7. `07-backend-architecture.md`
8. `08-tracking-analytics-pixels.md`
9. `09-deployment-env-and-docker.md`
10. `10-ai-coder-rules.md`

Supporting files:

- `sheet-order-columns.csv`
- `seed-products.csv`
- `google-apps-script-webhook.md`
- `claude-sonnet-4.6-prompt.md`
